# Kata 1 - Configuración de Proyecto Java en IntelliJ y Git

Este repositorio contiene una guía y un flujo de trabajo automatizado para la creación y gestión de clases en un proyecto Java utilizando IntelliJ IDEA y Git. El enfoque principal es maximizar el uso de atajos de teclado para minimizar la dependencia del ratón, mejorando la eficiencia y productividad del desarrollo.

## Requisitos previos

- IntelliJ IDEA instalado.
- Git instalado y configurado.
- Conocimientos básicos de Java y control de versiones.

## Instrucciones

1. **Iniciar un nuevo proyecto Java en IntelliJ:**
   - Abre IntelliJ IDEA.
   - Selecciona la opción para crear un nuevo proyecto.
   - Configura el proyecto como un proyecto Java.

2. **Inicializar un repositorio Git en el directorio del proyecto:**
   - Navega al directorio del proyecto.
   - Ejecuta el comando `git init` para inicializar un repositorio Git o desde la creación del proyecto.

3. **Maximizar el uso de atajos de teclado:**
   - Aprende y utiliza los atajos de teclado proporcionados por IntelliJ para crear clases, navegar por el código y gestionar archivos.
   - Minimiza el uso del ratón para agilizar tu flujo de trabajo.

4. **Familiarizarse con atajos esenciales de IntelliJ:**
   - **Creación de clases:** Utiliza `Alt + Insert` (Windows/Linux) o `Command + N` (Mac).
   - **Navegación entre archivos:** `Ctrl + Tab` (Windows/Linux) o `Command + E` (Mac).
   - **Búsqueda de archivos o métodos:** `Shift + Shift`.

5. **Realizar commits regulares:**
   - Durante el desarrollo, utiliza Git para registrar cambios frecuentemente.
   - Usa comandos como `git add .` y `git commit -m "Mensaje descriptivo"` o desde la ventana proporcionada por el IDE.

6. **Mensajes de commit descriptivos:**
   - Asegúrate de que cada commit tenga un mensaje claro que describa los cambios realizados.
   - Esto facilita el seguimiento del progreso del proyecto.
